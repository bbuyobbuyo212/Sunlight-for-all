협동조합 설립은 6단계로 진행합니다.

설립 6단계

  1. 발기인 모집
  2. 정관 작성
  3. 창립총회
  4. 설립 신고
  5. 설립 등기
  6. 사업자 등록

❶ 발기인 모집 : 조합원이 될 발기인 5인 이상을 모읍니다.

❷ 정관 작성 : 조합의 목적, 사업, 출자, 운영 규칙을 정합니다. 표준 정관 서식을 제공합니다.

❸ 창립총회 : 발기인이 모여 정관과 사업계획을 의결하고 임원을 선출합니다.

❹ 설립 신고 : 다음 서류 9종을 갖추어 시·도에 신고합니다. ( 설립신고서, 정관, 창립총회 의사록, 출자 1좌 금액·출자좌수 확인서, 사업계획서, 수입·지출 예산서, 발기인 명부, 임원 취임 승낙서 )

❺ 설립 등기 : 출자금 납입을 마치고 관할 등기소에 법인 등기를 합니다.

❻ 사업자 등록 : 관할 세무서에 사업자 등록을 합니다.

진행 방법

❶ 서식을 내려받아 작성합니다.

❷ 작성한 서류를 업로드합니다.

❸ 담당자가 검토한 뒤 상담으로 서류를 마무리합니다.

※ 작성 중인 내용은 임시저장할 수 있습니다.

※ 플랫폼은 서류를 자동으로 만들어 주지 않습니다.
